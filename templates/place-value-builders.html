Make numbers with blocks

Hundreds, tens, and ones blocks show the value of each digit. Add and remove blocks or exchange a group of ten. Every exchange keeps the same total.

Worked example: trade 10 ones for 1 ten

14 ones = 1 ten and 4 ones

One ten is worth ten ones, so the number stays 14. The zero in 40 means 0 ones; the zero in 105 means 0 tens.

Level path

  1. Levels 1–3: build with ones, then exchange ten ones for a ten and a ten back into ones.
  2. Levels 4–5: compare two-digit quantities and show 40 as 4 tens and 0 ones.
  3. Levels 6–7: build 105 and exchange ten tens for one hundred.
  4. Levels 8–10: compare three-digit numbers and regroup to build 206.

There is no timer and no score to lose. Use the buttons to build, ask for a hint, and retry as often as you like.
